## Scanner

Following the Lexical Syntax of Jay, TokenStream.java was adapted alongside ScannerDemo.java to scan a file (prog1.jay). During this process, the file's text is tokenized and put through a series of checks to determine the token's validity. For each token, a type and value is given.

For example, prog1.jay with the content of:

```text
//
/ < > <= a02 2 boolean else 
true ( )
```

Returns:

```output
Token 1 - Type: Comment - Value: //
Token 2 - Type: Operator - Value: /
Token 3 - Type: Operator - Value: <
Token 4 - Type: Operator - Value: >
Token 5 - Type: Operator - Value: <=
Token 6 - Type: Identifier - Value: a02
Token 7 - Type: Literal - Value: 2
Token 8 - Type: Keyword - Value: boolean
Token 9 - Type: Keyword - Value: else
Token 10 - Type: Literal - Value: true
Token 11 - Type: Separator - Value: (
Token 12 - Type: Separator - Value: )
```

## Parser

Following the Concrete Syntax of Jay, ConcreteSyntax.java was adapted alongside ParserDemo.java to parse a file (prog1.jay). During this process, the stream of tokens generated by the scanner is analyzed against the syntax of Jay, returning the abstract syntax of the program.

For example, prog1.jay with the content of:

```text
void main(){
int x, y;
x = 1;
y = 2;

while(x == 1) if(x<=y) y = y - 1; else x = x - 1;
}
```

Returns:

```output
Abstract syntax of the JAY Program: 
  Declarations: 
    Declarations = {<x, int>, <y, int>}
  Block: 
    Assignment: 
      Variable: x
      Value: 1
    Assignment: 
      Variable: y
      Value: 2
    Loop: 
      Binary: 
        Operator: ==
        Variable: x
        Value: 1
      Conditional: 
        Binary: 
          Operator: <=
          Variable: x
          Variable: y
        Assignment: 
          Variable: y
          Binary: 
            Operator: -
            Variable: y
            Value: 1
        Assignment: 
          Variable: x
          Binary: 
            Operator: -
            Variable: x
            Value: 1
```
